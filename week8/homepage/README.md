# CS50x Homepage

This project is a personal website about artificial intelligence, created as part of Harvard University's CS50x course.

## About the website

The website explains different aspects of artificial intelligence through five pages:

* **Homepage** — An introduction to artificial intelligence.
* **History** — A brief history of AI and its development.
* **Machine Learning** — An explanation of machine learning and its main types.
* **Applications** — Examples of how AI is used in different fields.
* **Future** — Potential benefits and challenges of future AI development.

## Technologies

The website was built using:

* HTML
* CSS
* Bootstrap
* JavaScript

The JavaScript adds an interactive button that displays a random AI-related fact.
