# CS50 Finance

My implementation of **Finance**, Problem Set 9 of [Harvard University's CS50x](https://cs50.harvard.edu/x/), a web application built with Python, Flask, SQLite, HTML, CSS, and JavaScript.

The application allows users to:

- Register and log in
- Look up stock prices
- Buy and sell stocks
- View their current portfolio
- View their transaction history
- Track their cash balance and total portfolio value

## My work

The application logic and database extensions were implemented by me as part of CS50x.

The project is based on the **CS50 Finance starter code** provided by Harvard's CS50 staff. Some files, HTML templates, helper functions, and other components were provided as part of the problem set and were not originally written by me.

I also used CS50's official problem set specification and documentation while implementing the project.

## Technologies

- Python
- Flask
- SQLite
- CS50 SQL library
- HTML / CSS
- Jinja
- JavaScript

## Running the application

This project is intended to be run in the CS50 Codespace using the dependencies and setup provided by CS50.

To start the Flask application:

```bash
flask run
```
