# Filter

> **Note:** Only `helpers.c` was written by me. The remaining files were provided by Harvard's CS50 as part of the problem set.

An image-processing program written in C as part of Harvard's CS50x.

## Filters

* **Grayscale**: Converts an image to grayscale.
* **Reflect**: Reflects an image horizontally.
* **Blur**: Applies a box blur to the image.
* **Edges**: Detects edges using the Sobel operator.

## Concepts

This project practices:

* 2D arrays
* Structs
* Image manipulation
* Nested loops
* The Sobel edge-detection algorithm
* Working with copies of data to avoid modifying the original while processing it
